# Withdrawn tag: v2.0.0 (2026-06-15)

The `v2.0.0` tag and GitHub release were **withdrawn on 2026-10-25**. This file
keeps their content for history.

## Why it was withdrawn

`v2.0.0` was tagged on commit `bc65199` ("chore: move local env template to
project root") on 2026-06-15. The project then continued on the 1.0 line, and
`v1.0.0` was tagged on 2026-07-03. That makes `v2.0.0` an **ancestor** of
`v1.0.0`: every semver-aware tool (`git tag --sort=-v:refname`, `go list -m`,
release dashboards) ranked the June commit above the current release, so
"latest by version" pointed at a four-month-old tree. `CHANGELOG.md` never had a
2.0.0 section, and no release notes were announced for it.

A published line is not renumbered. Removing the stray tag is the only fix that
makes `git describe` and the release list agree with `CHANGELOG.md`. The OpenAPI
document keeps its own `info.version` of `2.0.0`; that is the version of the API
contract document, not of the service release.

## Original release notes, as published

## fd v2.0.0

Same-host TEI embedding service release focused on the current production runtime, agent-native operations, and verified test gates.

### Highlights

- TEI-only production runtime with `deepvk/USER-bge-m3` at 1024 dimensions.
- OpenAI-compatible `/v1/embeddings` API with batch, dimensions, validation, auth, and cache behavior.
- Two-tier embedding cache: in-process L1 plus Redis L2.
- Authenticated cache controls:
  - `POST /v1/cache/flush`
  - `POST /v1/cache/delete`
- Runtime diagnostics:
  - `/health` runtime metadata, dependency reachability, last error context, and in-flight capacity.
  - `/metrics` runtime/cache gauges.
- Current test gates:
  - Go tests: 295 passing.
  - golangci-lint: 0 issues.
  - govulncheck: 0 reachable vulnerabilities.
  - Docker integration suite covering auth, embeddings, metrics, and cache invalidation.
  - Bounded mutation baseline for critical cache/handler/lifecycle files.
- Root `.env.example` added; real local `.env` is gitignored and used by Docker Compose when present.

### Verification before release

- `cd api && go test ./...` → 295 passed in 10 packages.
- `golangci-lint v2.12.2` with repo config → 0 issues.
- `govulncheck` → 0 reachable vulnerabilities.
- `cd tests/integration && FD_INTEGRATION_API_KEY=... go test -v .` → passed.

### Notes

- Request `model` remains compatibility metadata; response `model` and `/health.runtime.model` are authoritative.
- `/health` is metadata/reachability diagnostics, not an embedding inference proof; use a smoke embedding request for full readiness.
- ONNX runtime remains inactive/future research pending tokenizer parity.
