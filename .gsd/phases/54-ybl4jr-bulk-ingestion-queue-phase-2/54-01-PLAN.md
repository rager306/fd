# S01: Bulk ingestion queue MVP

**Goal:** Реализовать async bulk ingestion queue MVP: HTTP endpoints, in-memory bounded channel, time-windowed batched worker, status polling, backpressure, metrics.
**Demo:** POST /v1/queue -d '{"inputs":[...]}' → 202 Accepted с X-Request-Id. Позже GET /v1/queue/<id> → 200 {status:completed, data:[...]}. Batch visibility в /metrics.
